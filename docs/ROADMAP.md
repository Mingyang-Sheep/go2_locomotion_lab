# Roadmap

- Phase A: Competition Baseline
- Phase B: Competition HighStep
- Phase C: HIM Baseline (implemented; convergence training remains experimental)
- Phase D: Unified Evaluation
- Phase E: Domain Randomization
- Phase F: Sim2Sim
- Phase G: Sim2Real
- Phase H: LBC

Phase A remains frozen after its acceptance. HIM training, export, MuJoCo Sim2Sim,
and a safety-gated SDK2 adapter have now been added without changing the Competition
actor. Navigation, depth/camera observations, UWB, LBC, and hardware validation remain
out of scope.
